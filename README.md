# Aura Fasting Legal Center

Arquivos prontos para GitHub Pages.

## Como publicar

1. Envie estes arquivos para o repositório `aurafast-legal`.
2. No GitHub, acesse `Settings > Pages`.
3. Em `Source`, selecione `Deploy from a branch`.
4. Em `Branch`, selecione `main` e `/ (root)`.
5. Clique em `Save`.

Depois de publicado, os links devem ficar assim:

- Página inicial: `https://ellevationarts.github.io/aurafast-legal/`
- Política de Privacidade: `https://ellevationarts.github.io/aurafast-legal/privacy-policy.html`
- Termos de Uso: `https://ellevationarts.github.io/aurafast-legal/terms-of-use.html`
